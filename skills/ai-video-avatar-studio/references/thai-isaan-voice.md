# Thai and Isaan Voice

ใช้เอกสารนี้เมื่อ job ต้องมีเสียงพูดภาษาไทย ภาษาอีสาน หรือการโคลน/ปรับเสียงจากตัวอย่าง ให้แยก **ภาษา**, **สำเนียง**, **บุคลิกเสียง**, และ **สิทธิ์ของเสียงอ้างอิง** ออกจากกัน เพราะบริการจำนวนมากระบุเพียง locale ภาษาไทย `th-TH` และไม่ได้รับรองสำเนียงอีสานโดยตรง

## ลำดับการทำงาน

1. ตรวจข้อความกับเจ้าของภาษาหรือผู้รู้ภาษาอีสาน ให้แก้คำศัพท์ สำนวน ตัวสะกดที่ใช้ช่วยการออกเสียง และจังหวะการเว้นวรรค
2. แบ่งข้อความเป็นช่วงสั้นตามฉากและความหมาย ไม่สร้างเสียงก้อนเดียวที่ยาวเกินการควบคุม timing
3. เลือกเสียงจากรายการล่าสุดของ provider หรือใช้ ThonburianTTS/self-hosted เมื่อมีสภาพแวดล้อมเหมาะสม บันทึก `provider`, `model`, `voice`, `locale`, `speed`, `pitch` และ `sample_rate`
4. สร้าง preview สั้นที่มีคำยาก ตัวเลข ชื่อเฉพาะ และคำอีสานสำคัญ ให้เจ้าของภาษาตรวจการออกเสียง โทน และความเป็นธรรมชาติ
5. ปรับข้อความและจังหวะก่อนปรับความเร็วเสียง หากยังไม่พอดีให้ใช้ SSML/phoneme เฉพาะเมื่อบริการรองรับ และหลีกเลี่ยงการเร่งเสียงจนฟังไม่เป็นมนุษย์
6. ตรวจความดัง ความเงียบต้น/ท้าย เสียงแตก ลมหายใจที่ผิดธรรมชาติ และการออกเสียงซ้ำ จากนั้นจึงส่งเข้า Avatar/lip-sync
7. เก็บตัวอย่างเสียงและผลอนุมัติไว้ใน manifest ไม่เก็บเสียงอ้างอิงเกินระยะเวลาที่จำเป็น และย้ายไปถังขยะตามกฎ cleanup เมื่อเกี่ยวข้องกับ job

## การเขียนภาษาอีสาน

ให้คงคำและสำนวนที่ผู้ใช้ต้องการ แต่ควรใส่คำอ่านหรือรูปแบบที่ช่วยการออกเสียงในช่อง metadata แยกจากข้อความที่จะแสดงบนจอ หากไม่มี phoneme/SSML ให้ใช้การแบ่งคำและเครื่องหมายวรรคตอนอย่างระมัดระวัง ห้ามเปลี่ยนข้อความอีสานเป็นไทยกลางโดยอัตโนมัติเพียงเพื่อให้ TTS อ่านง่ายโดยไม่ขออนุมัติ

หากต้องใช้ voice adaptation หรือ voice cloning ให้ขอหลักฐานว่าผู้ใช้เป็นเจ้าของเสียงหรือได้รับ consent ที่ครอบคลุมการสังเคราะห์เสียง ตรวจว่า license อนุญาตการใช้งานเชิงพาณิชย์หรือไม่ และเปิดเผยใน metadata ว่าเป็นเสียงสังเคราะห์เมื่อจำเป็นต่อบริบท ห้ามเลียนเสียงบุคคลจริงที่ไม่มีสิทธิ์

## เกณฑ์ตรวจเสียงก่อนลิปซิงก์

| รายการ | ผ่านเมื่อ |
|---|---|
| ภาษาและสำเนียง | เจ้าของภาษายืนยันว่าเป็นไทย/อีสานตาม brief และไม่มีการปนสำเนียงที่ไม่ต้องการ |
| การออกเสียง | คำเฉพาะ ตัวเลข ชื่อ และคำอีสานสำคัญถูกต้อง |
| จังหวะ | มีช่วงหายใจและ pause เหมาะสม ไม่เร็วหรือช้าเกินไป |
| คุณภาพสัญญาณ | ไม่มี clipping, dropouts, robotic artifacts หรือเสียงพื้นหลังที่กลบคำ |
| ความยาว | ความยาวอยู่ใน budget ของฉากและไม่บังคับให้ Avatar ขยับปากเร็วผิดธรรมชาติ |
| สิทธิ์ | มี source/consent/license record ใน manifest |

## ตัวเลือกหลักที่ตรวจพบ

- **Google Cloud TTS:** ใช้ตรวจรายการ voice ภาษาไทยล่าสุดจากเอกสารทางการก่อนเลือกชื่อเสียงจริง
- **Azure Speech:** ตรวจ locale `th-TH`, neural voice และ region จาก language support ล่าสุดก่อนเรียก API
- **ThonburianTTS:** ใช้เป็น self-hosted Thai TTS เมื่อมี dependency/GPU และสิทธิ์ใน voice reference ที่เหมาะสม

อย่าสรุปว่า provider ใดรองรับภาษาอีสานโดยตรงจนกว่าจะฟังตัวอย่างจริงและให้เจ้าของภาษาตรวจ หากไม่มีเสียงที่เหมาะสม ให้เสนอการเขียนสคริปต์ใหม่ การบันทึกเสียงมนุษย์ที่ได้รับอนุญาต หรือ Avatar ที่ใช้เสียงต้นฉบับแทน TTS
