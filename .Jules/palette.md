# Palette's UX/Accessibility Journal

## 2026-02-26 - Improving loading state and accessibility focus
**Learning:** For long-running operations like video generation, providing immediate visual feedback is crucial to avoid user confusion and duplicate submissions. Using a standard focus style with a 3px box-shadow and `outline: 2px solid transparent` ensures accessibility across various contrast modes.
**Action:** Always include a loading state for form submissions and maintain a consistent focus style for all interactive elements.
