## 2026-05-17 - [Foundational UX for Video Generator]
**Learning:** Simple forms often overlook basic accessibility (labels, character limits) and feedback loops (loading states). In a tool like a video generator where processing takes time, a lack of feedback can lead to user frustration or multiple submissions.
**Action:** Always include immediate visual feedback for long-running actions and ensure every input has a semantic label, even if visually hidden.
