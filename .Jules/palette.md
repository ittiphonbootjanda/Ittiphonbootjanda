## 2025-05-14 - Loading states and accessible forms

**Learning:** Users need immediate feedback for long-running processes like video generation. Disabling the submit button and changing its text prevents duplicate submissions and provides clear status. Semantic labels and focus indicators are essential for accessibility.

**Action:** Always implement a loading state for form submissions that trigger long-running backend tasks. Ensure all form fields have associated <label> elements and clear focus-visible styles.
