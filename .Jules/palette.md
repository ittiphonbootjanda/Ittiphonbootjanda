## 2025-04-01 - Loading state and accessibility improvements
**Learning:** For long-running operations like video generation, providing immediate visual feedback by disabling the submit button and changing its text to "Generating..." prevents multiple submissions and manages user expectations. Using `setTimeout(..., 0)` in the submit event listener ensures that the form's POST request is initiated before the button enters a disabled state, avoiding potential cancellation in some browsers. Accessibility is improved by adding visually-hidden labels for form fields and ensuring clear focus-visible states for keyboard navigation.
**Action:** Always implement loading states for asynchronous or long-running form submissions, and use `setTimeout(..., 0)` if disabling the trigger element. Ensure all interactive elements have highly visible `:focus-visible` styles and semantic labels.
