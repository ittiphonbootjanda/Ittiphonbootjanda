## 2026-05-31 - [Loading Feedback & Accessibility]
**Learning:** Adding immediate visual feedback on long-running tasks (like video generation) prevents double submissions and improves perceived performance. Using visually-hidden labels ensures accessibility for screen readers while maintaining a clean minimalist design.
**Action:** Always include a disabled 'loading' state for buttons triggered by form submissions, and use the `.visually-hidden` pattern for semantic labels that don't need to be visible.
